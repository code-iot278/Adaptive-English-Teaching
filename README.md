# Adaptive-English-Teaching
Conditional Denoising Diffusion Generator Network with ThompsonSampling Bandit Inquiry for Adaptive English Teaching
Dataset 1 (Feedback Prize – English Language Learning / ELLIPSE
Corpus): Contains approximately 6,500 argumentative essays written by 8th12th
grade English Language Learners, scored on six analytic proficiency measures
(cohesion, syntax, vocabulary, phraseology, grammar, conventions) and a holistic
score.
https://www.kaggle.com/competitions/feedback-prize-english-language-learning/data
 Dataset 2 (Student Academic Performance &amp; Feedback Dataset): Contains 10,000
student records with features like attendance, study hours, assignment scores, and a
final performance grade. It also includes teacherprovided feedback categories (e.g.,
“needs grammar”, “excellent structure”). This dataset supplies the multidimensional
learner profiles for the inquiry engine.
https://www.kaggle.com/datasets/waqi786/student-performance-dataset

Both datasets are combined and partitioned into training (70 %), validation (15 %), and
testing (15 %) using stratified sampling on proficiency levels or performance grades.
